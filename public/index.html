Ferramentas de qualidade de software

Três ferramentas que apoiam a qualidade ao longo do ciclo de desenvolvimento: gerência de configuração, análise de código e integração contínua.

Git

Sistema de controle de versões distribuído. Registra cada mudança em commits rastreáveis, permite trabalhar em branches isoladas e recuperar qualquer versão anterior do projeto. É a base da gerência de configuração.

SonarQube

Plataforma de análise estática que inspeciona o código-fonte em busca de bugs, vulnerabilidades, code smells e duplicações, e acompanha métricas como cobertura de testes e dívida técnica.

GitHub Actions

Serviço de integração e entrega contínuas. Executa pipelines automaticamente a cada push ou pull request para validar, testar e publicar o sistema.
